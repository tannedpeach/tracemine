# Working agreements

Build the smallest complete trajectory-debugging workflow. Keep TODO.md current.
Never run agents or tests in a user's source repository. Preserve raw process logs.
Do not invent trajectories, measurements, or recovery outcomes. Tests passing only
means the supplied command passed. Keep dependencies and abstractions small.
Run backend tests and frontend type/build checks before committing milestones.
Never commit credentials, absolute machine paths, local run databases, or caches.
